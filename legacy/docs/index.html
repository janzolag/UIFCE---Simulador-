📊 Simulador Económico

Unidad Informática FCE · Universidad Nacional de Colombia

Bienvenido

Aplicación web interactiva para simular modelos económicos en las materias de Fundamentos, Microeconomía 1 y Macroeconomía 1. Desarrollada con tecnología moderna (Dash + Plotly) para visualizar conceptos económicos de forma dinámica e intuitiva.

📚 Materias disponibles

Fundamentos de Economía

6 simuladores: Equilibrio de mercado, elasticidades, excedentes, impuestos y subsidios, frontera de posibilidades de producción, ventaja comparativa.

Microeconomía 1

10 simuladores activos: Restricción presupuestal, preferencias, elección óptima, Slutsky, demanda, producción, costos, competencia perfecta, monopolio y oligopolio.

Macroeconomía 1

4 simuladores: Modelo Keynesiano, IS-LM, demanda y oferta agregadas, Mundell-Fleming (en desarrollo).

✨ Características

🎨 Interfaz moderna

Tema azul oscuro, responsive design, gráficas interactivas con Plotly.

📱 Multiplataforma

Funciona en desktop, tablet y móvil. Menú adaptable en pantallas pequeñas.

🔧 Arquitectura modular

Fácil de extender: agregar nuevos simuladores sin tocar el núcleo.

✅ Testeado

Motor matemático probado, pruebas de interfaz y navegador con Playwright.

💻 Instalación rápida

git clone https://github.com/janzolag/UIFCE---Simulador-.git
cd UIFCE---Simulador-
pip install -r requirements.txt
python app.py

Abre http://127.0.0.1:8050 en tu navegador. La versión en línea puede tardar ~1 minuto en despertar la primera vez (plan gratuito).
